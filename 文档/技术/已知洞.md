## 稳定性加固（API 替换后）已处理

| 原项 | 处理 |
|------|------|

## 仍接受（1.0 不修）

| 项 | 说明 |
|----|------|
| 队列 / 生成进度不落盘 | 重启或卸载世界后重新扫描；进行中的生成作废。见 README「已知限制」 |
| 启发式工艺链 | 大学分仍要求锯木+石匠+铁匠，启发式不建这三座。用固定式走完默认计划 |
| 固定式第 11 步 | BUILDER minLevel 2 count 1：可能升级现有建造者，不一定新建第二座 |
| 农田计数 | 固定式 FIELD 按全殖民地田数，但不超过当前农夫可挂上限；挂满则跳过多余的田，不升级农夫 |
| 瞬间建造 | 命令 `/beastofburden planningInstantBuild`，不写盘 |
| Mixin 启动方式 | 只用 `mods.toml` `[[mixins]]`；禁止 Gradle `mixin.config`（会在资源上 classpath 前读 json 而崩）。userdev 下该 config 常常不加载，Actions「牛马」入口以 `TownHallActionsBeastButton` 为准 |
| `PlannedBuildingType.capacityBuilding` | 枚举字段，计划编辑器用目录，规划器不读该标志 |
| 快照 `planningPhase` byte | 协议兼容占位，恒 0 |
| Job/AI/GUI core 基类 | 无对等 public API；编译钉 873；1214+ 仅对已确认硬崩溃做运行时兼容 |

策划已标明的非目标见 [产品定位.md](../策划/00-总览/产品定位.md)。
