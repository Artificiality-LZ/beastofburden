## 本地源码树里有什么

`minecolonies-release-1.20/` 是一份 **1.20.1 时代的上游快照**，用来在 IDE 里跳转、对照类职责。它 **不是** 本模组编译用的那份 jar（编译走 CurseMaven `6444411` → 运行时 **1.1.873**）。

### 规模（约）

| 区 | 路径 | 约 Java 数 | 说明 |
|----|------|------------|------|
| API | `src/api/java/com/minecolonies/api/` | ~610 | 对外接口、注册表、常量；插件应优先依赖这里 |
| 实现 | `src/main/java/com/minecolonies/coremod/` | ~1270 | 殖民地逻辑、AI、建筑、网络、GUI |
| API 实现桥 | `src/main/java/com/minecolonies/apiimp/` | ~25 | `CommonMinecoloniesAPIImpl` + 各类 `*Initializer` |
| 数据生成 | `src/datagen/` | — | 标签、语言、配方等生成输出 |
| 蓝图 | `src/main/resources/blueprints/minecolonies/` | 23 风格 | Structurize 蓝图包（acacia、original、pagoda…） |
| 旧 schematics | `src/main/resources/assets/minecolonies/schematics/` | — | 历史路径，新内容在 `blueprints/` |

### 内容清单（本地树可见）

- **建筑**：`ModBuildings` 含 townhall、builder、warehouse、farmer、deliveryman、各类工艺/畜牧/军事 hut；workerbuildings 约 40+ 个 `Building*`。
- **职业**：`JobBuilder`、`JobFarmer`、`JobDeliveryman`、守卫/学生/研究等约 40+；本模组新增 `beastofburden:beastofburden`。
- **蓝图风格**：23 个 pack 目录（original、medieval*、pagoda、fortress…）；规划用殖民地当前结构包 + `BlueprintMapping`。
- **请求系统**：api 侧 `request` / `requestable` / `resolver`（含 `IPlayerRequestResolver`、`IRetryingRequestResolver`）；core 侧有完整实现与 factory。
- **建筑模块接口**（api）：`IAssignsJob`、`IPersistentModule`、`ITickingModule`、`IBuildingEventsModule`、`IBuildingWorkerModule` 等——市政厅牛马模块实现这套。

## 已知脆弱点

1. 反射农田 / 胶带：混淆或改名即崩，不要换成「看起来更新」的 1214 API。
2. 模块侧栏：873 原生显示；1214 曾需要 mixin `shouldRenderDefaultSidebar`（已删除）。
3. `AbstractBlockHut.onBlockPlacedByBuildTool`、level 0 + requestUpgrade 是规划落 hut 的契约，改 MC 建造流程时必回归。
4. Job 模型必须 `SETTLER_ID`，`CITIZEN_ID` 会裁切。
5. 本地源码树包名落后于 873：能当地图，不能当 classpath 真相。

升版本 checklist：对照本页 API 与反射表 → 跑 `runClient` 开市政厅页 → 冷启动第一座建造者 → 卡住请求生成配送 → 固定式走完第 1–5 步。

### 建议阅读顺序（在本地树里）

1. `api/IMinecoloniesAPI.java` — 全局入口有哪些 registry  
2. `api/colony/buildings/ModBuildings.java` — hut id  
3. `api/colony/buildings/modules/*` — 模块契约  
4. `api/colony/requestsystem/**` — 补给挂钩  
5. `coremod`→实际 `core` 的 `AbstractJob` / `AbstractAISkeleton` / `BuildingTownHall` — 对照本模组基类  
6. 农田 / 胶带：先在 **873 jar / 反编译** 核对 FQN，再用本地树看逻辑（注意改名）
