## 873 树里有什么（主对照）

规模约：API + 实现合计 **~2006** 个 `.java`；实现根包已是 **`com.minecolonies.core`**（不是 `coremod`）。农田在 **`colony.buildingextensions`**。

| 区 | 路径 | 说明 |
|----|------|------|
| API | `src/main/java/com/minecolonies/api/`（873 树；旧文档曾写 `src/api/java`） | 对外接口、注册表、常量 |
| 实现 | `src/main/java/com/minecolonies/core/` | 殖民地逻辑、AI、建筑、网络、GUI |
| API 实现桥 | `src/main/java/com/minecolonies/apiimp/` | `*Initializer` |
| 蓝图 | `src/main/resources/blueprints/minecolonies/` | Structurize 风格包 |

### 873 vs 1214（快速对照）

两份都是 `core` + `buildingextensions`。1214 更新、类更多（约 2079 Java）；升版本前用 1214 树 diff 敏感 API（`FarmField` / `FarmerFieldsModule` / 胶带 / GUI 基类）。

旧复制 `minecolonies-release-1.20` 仍是 `coremod` + `colony.fields`，**不要**再当 873 真相。

## 已知脆弱点

1. **Core 编译依赖**：农田模块、胶带、Job/AI/GUI 基类仍钉在 `com.minecolonies.core`；升版本以编译错误为准。
2. 模块侧栏：873 原生显示；1214 曾需要 mixin `shouldRenderDefaultSidebar`（本模组已删）。
3. `AbstractBlockHut.onBlockPlacedByBuildTool`、level 0 + `requestUpgrade` 是规划落 hut 的契约；失败路径会回滚方块/注销建筑。
4. Job 模型必须 `SETTLER_ID`，`CITIZEN_ID` 会裁切。

升版本 checklist：对照本页 API / core 清单 → `compileJava` → 跑 `runClient` 开市政厅页 → 冷启动第一座建造者 → 卡住请求生成配送 → 固定式走完第 1–5 步（含农田）。
