# 产品定位

> 状态：**已实现**（核心两套玩法）  
> 玩家说明：[README.md](../../../README.md)  
> 技术对照：[../../技术/架构.md](../../技术/架构.md)

## 一句话

MineColonies **市政厅附加职业「牛马」**：在殖民地物流卡住时凭空生成并配送物资；可选地在建造者空闲时 **自主规划** 下一座小屋 / 农田 / 升级。

## 产品边界


| 做                           | 不做               |
| --------------------------- | ---------------- |
| 附加职业，挂在现有市政厅                | 独立小屋、独立殖民地系统     |
| 补「卡住的请求」，不是日常物流替代           | 不替代仓库 / 配送员的正常运转 |
| 规划 = 下工单给建造者（或调试瞬间粘贴）       | 不自己当建造者盖房子       |
| 固定式计划可编辑；启发式为实验             | 不做完整「殖民地 AI 总督」  |
| 兼容 MineColonies **1.1.873** |                  |


## 目标体验

1. 早期殖民地没有仓库/配送员时，请求不会永久卡死。
2. 玩家打开市政厅「牛马」页，能看到谁在干什么、进度条、历史。
3. 打开自主规划后，殖民地按计划（默认 12 步）或启发式打分往前长，而不是玩家逐座点建造。
4. 规划失败要能在 UI 上看见原因（重叠、无点、建造者忙等），而不是静默停住。



## 非目标（当前版本明确不做）

- 自动进行研究（1.0 已删除未接线的研究类与配置）
- 按 P0–P4 阶段推进（快照仍占位 byte 0；GUI 不再显示）
- 强制道路连通才允许落点（道路只影响打分与门口铺路）
- 把启发式做成完整建筑目录 / 工艺链（实验性；完整路径用固定式）
- 专用皮肤 / 语音（模型用 settler，语音复用 builder）
